# תוכנית עבודה שנתית – חינוך גופני

## שמירה בענן וניהול קודים

- **הזנת קוד** (כל משתמש): חלון הסנכרון ← הזנת הקוד ← "התחבר". הנתונים נטענים מיד.
- **הנפקת קוד חדש** (מנהל בלבד): הכפתור "שמירה בענן" פותח כניסה עם Google. רק אחרי אימות החשבון `tamirmaidani@gmail.com` נוצר קוד חדש.
- **עמוד ניהול קודים** (מנהל בלבד): בחלון הסנכרון יש את הכפתור "🔐 ניהול קודים", או בכתובת `index.html#admin`. בעמוד אפשר ליצור קוד חדש, לבטל קוד (ולהפעיל אותו מחדש), למחוק קוד יחד עם הנתונים שלו, ולחבר את המכשיר הנוכחי לקוד.

### הגדרה חד-פעמית ב-Firebase Console (פרויקט `pe-app-db`)

1. **Authentication › Sign-in method**: להפעיל את **Google**. גם **Anonymous** צריך להישאר מופעל.
2. **Authentication › Settings › Authorized domains**: להוסיף את הדומיין שבו האתר מתארח (למשל `t-code-now.github.io`).
3. **לפני פרסום החוקים**: להיכנס פעם אחת לעמוד ניהול הקודים עם חשבון המנהל. קודים קיימים מלפני השינוי נרשמים שם אוטומטית כפעילים, כך שמי שכבר משתמש בהם ימשיך לעבוד כרגיל.
4. **Firestore Database › Rules**: להעתיק את התוכן של `firestore.rules` ולפרסם (Publish). אפשר גם להריץ `firebase deploy --only firestore:rules`.

ההרשאות נאכפות בשרת דרך `firestore.rules`, ולא רק בדפדפן:
- רק החשבון `tamirmaidani@gmail.com`, עם כתובת מייל מאומתת, יכול ליצור, לבטל, למחוק או לראות את רשימת הקודים.
- כל מי שמחזיק קוד פעיל יכול לקרוא ולעדכן את הנתונים של אותו קוד בלבד.
- קוד שבוטל או נמחק נחסם מיד. מכשיר שמחובר לקוד כזה מקבל הודעה, והנתונים המקומיים שלו נשמרים.

כדי להחליף את חשבון המנהל צריך לעדכן את הכתובת בשני מקומות: `ADMIN_EMAIL` ב-`index.html` וב-`firestore.rules`.
